# Hello World Webpage

A simple "Hello World" webpage project with HTML, CSS, and JavaScript.

## Features

- Basic HTML structure
- CSS styling
- Interactive button that changes the background color
- Git and GitHub integration

## Usage

Open `index.html` in any web browser to view the webpage.

## GitHub Repository

This project is connected to a GitHub repository. To access it:

1. Edit the `connect_to_github.bat` file and replace `YOUR_USERNAME` with your GitHub username
2. Read the `setup_github_auth.md` file to set up proper authentication
3. Run the `connect_to_github.bat` script to push your code to GitHub

Alternatively, for SSH connection:
1. Edit the `connect_using_ssh.bat` file and replace `YOUR_USERNAME` with your GitHub username
2. Set up SSH keys as described in `setup_github_auth.md`
3. Run the `connect_using_ssh.bat` script to push your code
